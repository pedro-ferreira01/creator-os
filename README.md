# CreatorOS

> Operating System for Creators

A CreatorOS é uma plataforma em desenvolvimento com o objetivo de centralizar as principais ferramentas utilizadas por criadores de conteúdo em um único ambiente.

## Visão

Criar o sistema operacional definitivo para criadores de conteúdo.

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Turborepo
- PNPM
